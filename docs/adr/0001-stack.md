# ADR 0001: стек

Дата: 2026-11-21 · Статус: принято

ADR (Architecture Decision Record) — короткая запись «что решили и почему». Нужна, чтобы через
месяц не гадать, откуда взялось решение.

## Контекст

Локальное приложение для одного человека плюс ИИ-агент, который правит данные сам. Требования:
современный и популярный стек (портфолио), простой код, который легко менять по ходу, SQL в
основе (цель — BI/аналитика), аккуратный дизайн.

## Решение

| Слой | Выбор | Зачем |
|---|---|---|
| Язык бэкенда | Python 3.13, uv | Python уже знаком; uv — быстрый менеджер пакетов и окружений |
| API | FastAPI + Pydantic v2 | стандарт для API на Python, сам генерирует OpenAPI-схему |
| БД | SQLite, SQLAlchemy 2.0, Alembic | одна база-файл без сервера; Alembic — миграции схемы |
| CLI | Typer | CLI из обычных функций с типами; тот же доменный слой, что у API |
| Фронт | React 19, TypeScript, Vite | уже знакомы по прошлому проекту |
| Роутинг и данные | TanStack Router, Query, Table | типизированные маршруты, кэш запросов, дерево-таблица |
| UI | Tailwind CSS, shadcn/ui (Radix), Motion, Sonner, cmdk | код компонентов лежит у нас и правится; анимации, уведомления, `Ctrl+K` |
| Формы | react-hook-form + zod | проверка полей |
| Графики | Recharts (через shadcn charts) | единый стиль с интерфейсом |
| Типы API → фронт | openapi-typescript | типы фронта генерируются из схемы FastAPI: поменял API — компилятор покажет, что сломалось |
| Живое обновление | SSE + `PRAGMA data_version` | правки из CLI появляются в UI без перезагрузки |
| Качество | ruff, mypy, pytest; Biome, Vitest, Playwright; GitHub Actions | линт, типы, тесты, CI |
| Позже | FastMCP (MCP-сервер), Tauri (desktop-окно) | orbit как инструменты для любой сессии Claude; отдельное окно |

Точные версии фиксируем при установке (`uv add`, `npm view <pkg> version`), не по памяти.

## Рассмотрели и отказались

- **Streamlit**: быстро, но выглядит как Streamlit, слабое дерево и правка в ячейках.
- **FastAPI + HTMX**: проще, но менее популярный фронт и слабее для портфолио.
- **Next.js**: серверный рендеринг локальному приложению не нужен, лишняя сложность.
- **PostgreSQL**: нужен сервер; SQLite хватает одному пользователю, SQL тот же.
- **Desktop сразу (Electron/Tauri)**: сначала веб на localhost, окно добавим, когда UI устоится.

## Последствия

- Два языка (Python и TypeScript) — больше учёбы, зато обе части стандартны для индустрии.
- Генерация типов из OpenAPI связывает фронт и бэк: шаг `npm run gen:api` после изменений API.

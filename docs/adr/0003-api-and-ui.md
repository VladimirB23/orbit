# ADR 0003: API, живое обновление и интерфейс

Дата: 2026-11-24 · Статус: принято

## Контекст

Этап 2: браузерный интерфейс поверх домена этапа 1. Требования: удобно для человека, код
не ломается от правок (впереди аналитика, планер с календарем, агент в Telegram), безопасно для данных.

## Решение

**Главный экран: дерево со сводкой.** Счетчики сверху (в работе, заблокировано, просрочено, 7 дней)
фильтруют дерево. У свернутого проекта вторая строка: текущий этап и сигналы изнутри. Признаки
`upcoming`, `signals`, `focus` считает домен, интерфейс только показывает. Текущее (`focus`): этап в
работе, иначе задача в работе, иначе следующий открытый этап.

**API `/api/v1`** (FastAPI). Тонкий слой: один запрос = одна транзакция, коммит до ответа. PATCH шлет
только измененные поля, `null` очищает. Ошибки одной формы `{"error": {"type", "message"}}`. Автор
правок из интерфейса всегда `vladimir`, `ORBIT_ACTOR` сервера не учитывается.

**Живое обновление.** Отдельное соединение раз в 0,5 с читает `PRAGMA data_version` и текущую дату
(от нее зависят просрочки). По SSE уходит только «изменилось», клиент перечитывает данные.

**Безопасность без логинов.** Сервер слушает только `127.0.0.1`, это не настраивается. Проверяются
`Host` (DNS rebinding: чужой домен, указывающий на наш компьютер), `Origin` и `Sec-Fetch-Site` (CSRF:
чужая вкладка шлет запрос от твоего имени). CSP запрещает чужие скрипты; шрифты и код локальные,
Swagger выключен (берет скрипты из сети). Ссылкой становится только адрес `http(s)`.

**Сохранность.** `orbit serve` раз в день делает копию в `data/backups` (хранит 14, ручные не трогает).
Перед миграцией базы с данными копия делается автоматически.

**Чтобы не ломалось.** Типы фронта генерируются из схемы API; тест `test_contract.py` падает, если
схему забыли обновить. `bin/check` гоняет линт, типы, тесты и сквозные сценарии в Edge на отдельной
демо-базе. Правила считаются в одном месте (домен), слова интерфейса в `frontend/src/lib/status.ts`.

## Рассмотрели и отказались

- **TanStack Table, react-hook-form, zod, Motion** из ADR 0001: пока не нужны. Строки трех разных
  типов разворачивает функция на 60 строк с тестами, форма одна и на два поля. Понадобятся - добавим.
- **Пакет `cn`** (его ставит новый shadcn): версия 0.x, ему несколько недель. Взяли clsx + tailwind-merge.
- **Блокировка одновременной правки поля**: журнал хранит старое значение, а PATCH по одному полю
  почти исключает конфликт. Черновик в открытом поле обновлением не затирается.
- **TypeScript 7**: генератор типов с ним не проверен, взята 6.0.3.

## Последствия

- **Агент в Telegram** сможет ходить в тот же `/api/v1` с этого компьютера. Для доступа снаружи нужны
  токены и отдельный `actor` (миграция: CHECK в схеме) - отдельный ADR, до этого сервер наружу не открывать.
- **Новый экран** (таймлайн, аналитика, планер) = маршрут в `router.tsx` и папка в `features/`.
- Инструменты фронта запускаются через `scripts/run.mjs`: VS Code открывает проект как `d:\`, а Node
  видит `D:\`, из-за чего в сборку попадают два React.

# ADR 0004: ссылки наружу, журналы сессий, палитра команд

Дата: 2026-11-24 · Статус: принято

## Контекст

Этап 3: из трекера надо попадать туда, где идет работа (папка в VS Code, заметка в Obsidian), и видеть,
что делалось в сессиях Claude. После первой пробы понадобился адрес папки проекта на виду.

## Решение

**Ссылки строит интерфейс, в базе только пути.** `repo_path` становится `vscode://file/...` (с
`windowId=_blank`: иначе папка может заменить открытую), `obsidian_path` - `obsidian://open?vault=...`.
Ссылкой становится только локальный абсолютный путь. Сетевые (`\\server\share`) запрещены: их открытие
может отправить чужому серверу хеш пароля Windows. Адрес папки виден в дереве и в панели любого пункта.

**Настройки рядом с базой.** `data/orbit.db` -> `data/orbit.toml`, одна настройка `vault`. Файл не в git,
личный путь в код не попадает, демо-база настоящий vault не видит. `ORBIT_VAULT` важнее файла.
API отдает только имя vault, не путь.

**Сессии импортируются из журналов в vault,** а не из транскриптов Claude. Журнал - готовый короткий
итог, его формат наш (хук `obsidian_session_log.py`), и он не удаляется вместе со старыми транскриптами.
Vault только читается. Ключ - id сессии (принимается только UUID: он попадает в команду для терминала),
поэтому повторный импорт обновляет, а не дублирует. Папка в `Inbox` = slug проекта; незнакомые папки
пропускаются и называются в отчете, проекты сами не создаются.

**Импорт сам, без хука.** `orbit serve` раз в 15 с смотрит на время изменения журналов и список проектов,
читает только при отличии. Битый файл не роняет сервер, следующая попытка через 15 с.

**Сессии не пишутся в `events`.** Журнал изменений - про правки плана. Сессии - факты о прошлом, у них
нет «кто поменял», а у `events` есть ограничение на вид сущности. Аналитика этапа 5 берет их из `sessions`.

**`Ctrl+K` без библиотеки.** Окно на Radix, порядок результатов - чистая функция с тестами
(`lib/palette.ts`): начало названия, начало слова, середина, путь; закрытое ниже; понимает чужую раскладку.

## Рассмотрели и отказались

- **cmdk** (был в ADR 0001): последняя версия 1.1.1, с августа 2025 реестр без изменений. Наших 350 строк
  достаточно, а порядок результатов полностью наш.
- **Разбор транскриптов `.jsonl`**: полнее (все файлы, весь текст), но формат внутренний и может
  поменяться, а в базу попало бы личное.
- **Импорт из хука SessionEnd**: работает и без сервера, но связывает хук всех проектов с orbit.
- **Переменная окружения вместо файла**: пришлось бы менять настройки Windows.
- **Прописать vault в коде**: личный путь в будущем публичном репозитории.

## Последствия

- Поменялся формат журнала в хуке - меняется `backend/src/orbit/journal.py` и его тесты; непонятые
  записи видны в `orbit session import` (`entry not understood`).
- В журнале до 8 имен файлов и счетчик остальных, поэтому `files` - число, без списка.
- Сессия, к которой вернулись через день, имеет длинный период: часы работы по нему считать нельзя.
